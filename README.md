**Fullstack Software Engineer at [Bemobi](https://www.bemobi.com)** · Rio de Janeiro, Brazil · 6+ years building software

I build backend services in **Go**, web apps in **React/Next.js** and the **AWS** infrastructure they run on, for high-availability payment and telecom platforms used by millions of people in Brazil and LatAm.

- ⚙️ **Backend:** Go microservices for mission-critical B2B platforms, REST and event-driven integrations, message queues
- 🖥️ **Frontend:** React and Next.js PWAs for Brazil's largest telecom carriers; led the migration of a shared React monolith to micro-frontends
- 💳 **Payments:** Apple Pay, Google Pay and NuPay in top-up journeys; TikTok in-app mobile top-up with telecom partners
- ☁️ **Cloud & DevOps:** AWS, Terraform (IaC), Docker, Kubernetes, CI/CD, observability (Kibana, CloudWatch) and FinOps
- 🤖 **AI-assisted engineering:** Claude Code, Cursor and MCP, including Figma-to-code automation tools
- 🧭 **Practices:** clean architecture, SOLID, design patterns, automated testing, mentoring
